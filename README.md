Multi-Project Repository

This repository contains three beginner-to-intermediate projects: a simple ATM simulator, a Rock Paper Scissors game, and a Driving Federation website that checks license eligibility based on applicant age.

Projects
1. Basic ATM

A simple ATM simulation that allows users to perform common banking operations.

Features:

Balance inquiry
Cash withdrawal
Cash deposit
PIN verification

How to run:

bash
python ATM.py
2. Rock Paper Scissors

A classic Rock Paper Scissors game where the user plays against the computer.

Features:

Randomized computer choice
Win/loss/draw logic
Replay option

How to run:

bash
python game.py
3. Driving Federation Eligibility Checker

A website for a driving federation that checks whether an applicant is eligible to apply for a driving license based on their age.

Features:

Age-based eligibility check
Simple, user-friendly interface
Instant feedback on application eligibility

How to run:

bash
python "Driving Federation.py"
Getting Started

To get a local copy of this repository up and running, follow these steps:

bash
git clone https://github.com/Dionysus-ectasy/Ynwa.git
cd Ynwa

Then navigate into whichever project folder you'd like to run and follow the individual instructions above.
